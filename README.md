# Song of Philadelphia - Interactive Map

Interactive map that shows locations from in the podcast [Song of Philadelphia](https://podcasts.apple.com/us/podcast/song-of-philadelphia/id1771224001) by Julien Suaudeau.

# How to build and run

This repository requires [Node.js](https://nodejs.org/en) and uses [Cesium](https://cesium.com) for the geospatial rendering, [Google Street View Panaramas](https://developers.google.com/maps/documentation/javascript/streetview), and [Lil-GUI](https://lil-gui.georgealways.com/) for additional UI elements.

Install dependencies

```
npm install
```

Run a local web server

```
http-server -c10
```
